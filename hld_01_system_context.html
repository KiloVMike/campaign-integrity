Client-Side Outbox Pattern Every user action is written to local SQLite first with an Idempotency-Key UUID. Background sync guarantees delivery across process kills and network drops.
Observability & Diagnostics Stateless API emits structured JSON logs with correlation IDs, domain state metrics, and audit entries to monitoring sinks for rapid incident troubleshooting.
✓ In Scope (Owned & Guaranteed)
  • Immutable revision control tree & copy-on-write
  • SHA-256 cryptographic content verification
  • Single atomic schedule gate (PostgreSQL row lock)
  • Automatic schedule cancellation on post-approval edit
  • Local SQLite outbox & idempotent command sync
  • Tamper-evident append-only audit trail
  • Strict segregation of duties enforcement
✕ Out of Scope (Honest Non-Goals)
  • Ad network publishing (Meta Ads, Google Ads)
  • Creative media rendering, video CDN, asset store
  • Payment gateway billing & spend reconciliation
  • Push notifications / email delivery transport
  • SSO & multi-tenant enterprise isolation
  • Dual multi-party approvals (deferred to ADR-001)
Campaign Integrity Architecture: "The campaign that gets scheduled is the exact campaign that was approved."
