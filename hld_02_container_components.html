📱 Mobile Client Container
React Native · Expo · TypeScript
Screens & UI Components Campaign dashboard, revision comparison, review drawer, action triggers
Presentation
View Models & Use Cases Orchestrates reads, handles form state, dispatches commands to repositories
Application
Mobile Domain Helpers Pure TypeScript display logic & local form validations (never decides approval)
Pure Logic
Local Repositories Abstracts storage, queries local read projection, enqueues to outbox
Data Port
SQLite Read Cache & Outbox Sync Engine Persists command intent before network send; handles retries & process kill recovery
Persistence
Mobile Rule: Client never locally advances state to APPROVED. UI only displays "Confirming approval..." until server confirms.
⚙️ Server API Container
Node.js · Express · TypeScript · PostgreSQL
HTTP Transport & Middleware Layer JWT / role auth, schema parsing, Idempotency-Key extraction, error envelopes
Transport
Application Services Transaction management, command orchestration, authorization & audit emission
Application
Domain Model (Core Invariants) State machine, eligibility predicate, canonical SHA-256 hash, copy-on-write fork
Domain Core
Server Persistence Repositories SQL queries, row-level locking (SELECT FOR UPDATE), constraint error mapping
Data Adapter
PostgreSQL ACID System of Record Immutable revision log, append-only audit_events, idempotency_keys table
Database
Dependency Rule: Domain imports NOTHING from Express, SQL, or React. Presentation ➔ Application ➔ Domain ➔ Data implements ports.
📤 Outbox Command Sync: Client sends POST /v1/... with Idempotency-Key: <UUID>
📥 Confirmed Projection: Server returns authoritative snapshot; client writes directly to SQLite
🛡️ Deterministic Conflict: Stale revision or hash mismatch returns 409 Conflict (never silent overwrite)
Design Integrity: Modular monolith guarantees one atomic transaction for state transitions, eliminating distributed sagas.
