🔐 Segregation of Duties
Enforced in the application service layer: actor_id ≠ campaign.creator_id. Reviewers cannot approve their own campaigns. Authors cannot review their own proposals.
🛡️ Replay & Crash Defense
Client-generated UUID idempotency keys stored with request hash and response payload. Duplicate or retried requests replay the exact response without re-executing side effects.
📜 Tamper-Evident Audit Trail
Every committed state transition inserts an audit_events row with actor ID, timestamp, revision ID, SHA-256 hash, and correlation ID within the same ACID transaction.
🔒 Concurrency Protection
PostgreSQL row-level locks (SELECT FOR UPDATE) serialize concurrent reviews and schedule requests. Partial unique index guarantees zero duplicate active schedules.
Deployment Foundation: Stateless API horizontally scales freely; coordination and consistency are maintained by PostgreSQL ACID guarantees.
