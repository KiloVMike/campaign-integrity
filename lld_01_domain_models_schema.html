LLD Section 5
campaigns Campaign Container & Lock Root
id (PK)TEXT (CMP-...)
created_byTEXT NOT NULL
current_rev_id (FK)TEXT NOT NULL
created_atTIMESTAMPTZ NOT NULL
updated_atTIMESTAMPTZ NOT NULL
Lock Target: Serializes concurrency via SELECT * FROM campaigns FOR UPDATE.
revisions Immutable Version Tree
id (PK)TEXT (REV-...)
campaign_id (FK)TEXT NOT NULL
revision_numberINTEGER NOT NULL
stateRevisionState ENUM
objective, audienceTEXT NOT NULL
channel, budget_paiseENUM, BIGINT
content_hashCHAR(64) SHA-256
Copy-on-Write: Edits insert a new row; prior revision marked SUPERSEDED.
decisions Cryptographically Bound Approval
id (PK)TEXT (DEC-...)
campaign_id (FK)TEXT NOT NULL
revision_id (FK)TEXT NOT NULL
reviewer_idTEXT NOT NULL
outcomeAPPROVED | CHANGES_REQ
content_hashCHAR(64) SHA-256
noteTEXT (Required if changes)
Derived Approval: Valid iff rev.id = dec.rev_id ∧ rev.hash = dec.hash.
schedules Atomic Eligibility Gate Target
id (PK)TEXT (SCH-...)
campaign_id (FK)TEXT NOT NULL
revision_id (FK)TEXT NOT NULL
decision_id (FK)TEXT NOT NULL
stateSCHEDULED | CANCELLED
scheduled_atTIMESTAMPTZ NOT NULL
Partial Unique Index: Exactly one active SCHEDULED row per campaign allowed.
audit_events Tamper-Evident Domain Trail
id (PK)TEXT (AUD-...)
actor_idTEXT NOT NULL
event_typeAuditEventType ENUM
campaign_id, rev_idTEXT NOT NULL
correlation_idUUID NOT NULL
payloadJSONB NOT NULL
created_atTIMESTAMPTZ DEFAULT now()
Insert-Only: Database permissions revoke UPDATE and DELETE.
idempotency_keys Crash & Replay Defense
key (PK)TEXT (UUID)
actor_idTEXT NOT NULL
request_hashCHAR(64) SHA-256
statusIN_FLIGHT | COMMITTED
response_statusINTEGER
response_bodyJSONB
expires_atTIMESTAMPTZ NOT NULL
Exactly-Once: Duplicate requests return cached response body directly.
Referential Integrity: All revision references are immutable foreign keys. Deleting active campaigns is prohibited.
