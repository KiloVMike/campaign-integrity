Derived State Principle

A campaign does not possess an is_approved boolean column. Approval is derived dynamically from (current_rev, active_decision, matching_hash). If content changes, the hash changes, invalidating approval instantly without background sync.

Materiality in Version 1

Every proposal field (objective, audience, channel, budget_paise) is strictly material. Any modification whatsoever invalidates the content hash and requires full reviewer re-evaluation.

Zero Split-Brain

The client mobile app never advances state optimistically. While a command is in-flight, it shows a "Confirming..." banner. Authority resides exclusively with PostgreSQL transaction commits.

Deterministic Lifecycle: Unapproved states cannot transition to SCHEDULED. Stale approvals yield 409 Conflict.
