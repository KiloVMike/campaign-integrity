LLD Section 6 & 7
POST /v1/campaigns
Creates campaign container + Revision 1 (DRAFT). Requires Idempotency-Key header.
POST /v1/campaigns/:id/submit
Locks revision and moves to IN_REVIEW. Computes initial canonical SHA-256 content hash.
POST /v1/campaigns/:id/decisions
Reviewer signs APPROVED or CHANGES_REQUESTED with mandatory written rationale. Binds hash.
PATCH /v1/campaigns/:id
Copy-on-write edit. Supersedes current revision, forks new DRAFT, cancels active schedule.
POST /v1/campaigns/:id/schedule
Atomic schedule gate. Requires revisionId, expectedContentHash, and scheduledAt.
Deterministic Conflict Taxonomy (409)
409 REVISION_STALE
Requested revision ID does not match campaign.current_revision_id. Another user updated the proposal.
409 APPROVAL_INVALID
Current revision is in DRAFT or CHANGES_REQUESTED. Scheduling attempted without reviewer sign-off.
409 CONTENT_HASH_MISMATCH
Decision content hash differs from revision SHA-256 hash. Detects silent tampering or corruption.
409 ALREADY_SCHEDULED
Active schedule already exists for this campaign container. Prevents double-scheduling races.
403 SELF_REVIEW_PROHIBITED
Actor attempted to approve their own proposal. Strict separation of duties violation.
Deterministic Responses: Every conflict returns code + current revision snapshot for instant client reconciliation.
