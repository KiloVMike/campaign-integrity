1 Executive Architectural Blueprint

This document specifies the concrete modules, interfaces, models, states, database schemas, and the atomic scheduling transaction for Campaign Integrity. The design eliminates boolean status drift by binding every approval cryptographically and relationally to an immutable revision tree.

4 Canonical Content Hashing (SHA-256)

Every proposal revision computes a canonical SHA-256 hash across material fields to guarantee bit-level integrity:

function computeCanonicalHash(rev: ProposalContent): string { const payload = JSON.stringify({ objective: rev.objective.trim(), audience: rev.audience.trim(), channel: rev.channel, budgetPaise: rev.budgetPaise.toString() }); return crypto.createHash("sha256").update(payload, "utf8").digest("hex"); }

5 Critical Feature: Atomic Scheduling Transaction

Scheduling is evaluated within a single PostgreSQL ACID transaction under exclusive row-lock (SELECT ... FOR UPDATE). Zero race windows exist between concurrent edits and reviewer actions:

6 Transaction Implementation (TypeScript)

export class ScheduleService { async schedule(cmd: ScheduleCommand, ctx: RequestContext): Promise<ScheduleResult> { return this.pg.transaction(async (tx) => { // 1. Acquire exclusive lock on campaign root const campaign = await tx.query("SELECT * FROM campaigns WHERE id = $1 FOR UPDATE", [cmd.campaignId]); // Check 1: Current revision check if (cmd.revisionId !== campaign.current_revision_id) { throw new ConflictError("REVISION_STALE", { current: campaign.current_revision_id }); } // Check 2: Approved state check const rev = await this.revRepo.getById(tx, cmd.revisionId); if (rev.state !== "APPROVED") { throw new ConflictError("APPROVAL_INVALID", { state: rev.state }); } // Check 3: Cryptographic content hash equality const dec = await this.decRepo.getActiveDecision(tx, rev.id); if (dec.contentHash !== rev.contentHash) { throw new ConflictError("CONTENT_HASH_MISMATCH"); } // Check 4: Schedule uniqueness check if (await this.schedRepo.hasActiveSchedule(tx, campaign.id)) { throw new ConflictError("ALREADY_SCHEDULED"); } // Commit schedule and audit event atomically const schedule = await this.schedRepo.create(tx, { campaignId: campaign.id, revId: rev.id, decId: dec.id }); await this.auditRepo.emit(tx, { type: "CAMPAIGN_SCHEDULED", campaignId: campaign.id, revId: rev.id, actorId: ctx.actorId }); return schedule; }); } }

8 Defensibility Matrix & Quality Guarantees

Quality AttributeConcrete Failure ScenarioArchitectural Defense Mechanism
Integrity Marketer alters budget post-approval and attempts schedule. Copy-on-write supersedes revision; hash mismatch rejects schedule via atomic gate.
Recoverability App crashes or loses connectivity mid-command. Client SQLite outbox retains intent; background sync retries with identical UUID key.
Concurrency Reviewer approves while marketer submits simultaneous edit. PostgreSQL row lock (SELECT FOR UPDATE) on campaign serializes execution.
Auditability Auditor inspects historical decision for regulatory review. Append-only audit_events logs actor, timestamp, revision ID, hash, and request ID.
