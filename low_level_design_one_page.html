2 Revision State Machine & Mutations
TransitionTrigger ActionEnforced Guard
DRAFT ➔ IN_REVIEW Submit for review Author only; complete fields
IN_REVIEW ➔ APPROVED Reviewer approves reviewer ≠ author ∧ hash_match
IN_REVIEW ➔ CHANGES_REQ Request changes Mandatory written rationale note
APPROVED ➔ SCHEDULED Schedule campaign Single atomic gate checks pass
APPROVED ➔ SUPERSEDED Post-approval edit Copy-on-write fork; cancels schedule!
3 Clean Architecture Layer Boundaries
Mobile Client: Presentation ➔ Use Cases ➔ Domain Helpers ➔ Repositories ➔ SQLite Outbox.
API Monolith: HTTP Transport ➔ Application Services (Tx Boundary) ➔ Domain Core ➔ Persistence Repositories ➔ PostgreSQL.
Dependency Rule: Domain core imports NOTHING from Express, SQL, or React Native.

// ScheduleService.execute() inside PostgreSQL transaction: const c = await tx.query("SELECT * FROM campaigns WHERE id=$1 FOR UPDATE", [id]); if (req.revId !== c.current_revision_id) throw new ConflictError("REVISION_STALE"); const rev = await getRevision(tx, req.revId); if (rev.state !== "APPROVED") throw new ConflictError("APPROVAL_INVALID"); const dec = await getActiveDecision(tx, rev.id); if (dec.content_hash !== rev.content_hash) throw new ConflictError("HASH_MISMATCH"); if (await hasActiveSchedule(tx, c.id)) throw new ConflictError("ALREADY_SCHEDULED"); await insertSchedule(tx, ...); await insertAudit(tx, "CAMPAIGN_SCHEDULED", ...);

6 Resilience & Defensibility Tactics
SQLite Command Outbox: Persists user intent locally prior to dispatch; sync engine recovers seamlessly after app kill.
Exactly-Once Idempotency: Client UUID keys guarantee retried requests return cached responses with zero duplicate state mutations.
Derived Not Stored: Approval is computed dynamically. Eliminates mutable boolean drift entirely.
